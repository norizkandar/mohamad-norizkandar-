## Website Features

- Minimalist futuristic visual design with responsive layouts for desktop and mobile.
- Animated intro with a skip option.
- About section, personal snapshot, future ambitions, interests, and project showcase.
- Project filtering and search.
- Command palette with **Ctrl + K** on Windows/Linux or **Cmd + K** on macOS.
- Idea Vault and saved display preferences using the browser's local storage.
- Learning roadmap and glossary for development notes.
- Accessibility options, including reduced-motion support.
- SEO metadata, canonical URL, Open Graph and social-sharing metadata.
- Person structured data using JSON-LD.
- Google Search Console HTML verification tag.

## Run Locally

1. Download or clone this repository.
2. Keep the project files in the same folder structure.
3. Open `index.html` in a web browser.

The portfolio is designed as a static website and does not require a build step for its basic pages.

## Deploy with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Select the branch and folder used for deployment (for example, `main` and `/root`, depending on the repository setup).
4. Save the settings and wait for GitHub Pages to publish the site.
5. Open the published URL and test it on both desktop and mobile.

When updating the website, commit the changed files to the deployment branch. GitHub Pages will publish the committed version after its deployment process completes.
